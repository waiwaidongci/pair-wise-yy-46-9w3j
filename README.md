# 商业财产保险理赔查勘与定损审核工作台

面向理赔员、专家与主管的商业财产险查勘工作台，覆盖损失科目、修复报价、残值、责任比例、准备金会签、争议项、附件版本和审计时间线。

## 技术栈

Angular + Angular Material + NgRx + Angular Router + HttpClient + RxJS + Angular CLI + TypeScript

## 本地运行

```bash
npm install
npm run start
```

访问 `http://localhost:62046`。

## 核心工作流

- 按案件和损失科目录入查勘事实、照片、报告与保单摘录。
- 调整修复报价时强制填写理由，并保留前后差异。
- 准备金按金额与风险阈值触发多级会签，可退回补件。
- 会签全部通过后自动生成**唯一一份待生效支付依据**（「资金台账」页）。
- 两人同时提交付款确认时**先到者生效**，后到内容原样写入冲突记录，不覆盖、不重复记账。
- 残值回收 / 追偿回款到账即冲减未结金额；超额回款自动登记对账问题。
- 金额改动或登记对账差异会使原支付依据**失效**（垫付流水红冲但留痕）并**重算准备金**、回到会签。
- 付款失败后**按原支付号重试**，沿用同一依据，成功才补记垫付；重复提交幂等。
- 主管总览的已付、已回款、未结金额全部由同一资金台账派生，不再分叉。
- 对比赔付方案、定位争议项、上传附件版本并导出完整审计记录。

## 资金台账口径

| 指标 | 口径 |
| --- | --- |
| 已付 | 台账中未被冲销的「垫付」流水合计 |
| 已回款 | 「残值回收」+「追偿回款」流水合计 |
| 未结 | `max(0, 生效垫付 − 已回款)` |
| 准备金 | 定损口径重算：`Σ max(0, 最新报价 − 残值) × 责任比例 − 免赔额` |

台账引擎不变量可通过 `npm run test:ledger` 验证（单依据、并发竞争、回款冲减、失效重算、原号重试幂等等 14 项断言）。
